Novo mapa

🖼️ Arraste a imagem aqui, ou clique pra escolher (webp de preferência — é o mais leve)

A imagem enviada fica em assets/cenas/ no servidor. Enviar outra com o mesmo nome substitui a anterior.

ZOOM

Arraste em cima da imagem pra criar um ponto clicável. Clique num ponto pra editar, arraste pra mover, use o quadradinho do canto pra redimensionar. Nada é salvo até você clicar em Salvar pontos. O zoom é só pra você mirar melhor — não muda nada do que o aluno vê.

Lições

suba o JSON dos blocos (leitura, flashcard, cloze, caça-palavras, vídeo, quiz)

Nova lição

📄 Arraste um arquivo .json aqui, ou clique pra escolher — ou cole o JSON direto no campo abaixo
tipos de bloco aceitos 
texto        { paragrafos: [string, ...] }   -- use [[termo|explicação]] pra criar um popup clicável
flashcard    { cartas: [{frente, verso}, ...] }
video        { videoId: "ID do YouTube", titulo }
cloze        { frase: "...___...", opcoes: [string,...], certa: "texto igual a uma opção" }
cacapalavras { palavras: ["PALAVRA", ...] }   -- 3 a 10 letras MAIÚSCULAS cada
pergunta     { p: "...", alts: [string,...], certa: índice numérico da alternativa certa }
